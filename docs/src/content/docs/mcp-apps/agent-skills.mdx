[Agent Skills](https://agentskills.io/) steer coding agents. Mountly ships four
so an agent scaffolds Views with `mountly-mcp`, not by cloning SDK examples.

| Skill                                                                                                                       | Job                                   | Ask for                             |
| --------------------------------------------------------------------------------------------------------------------------- | ------------------------------------- | ----------------------------------- |
| [`create-mcp-app`](https://github.com/jagreehal/mountly/blob/main/plugins/mountly-mcp/skills/create-mcp-app/SKILL.md)       | `mountly-mcp create`                  | "Create an MCP App"                 |
| [`add-app-to-server`](https://github.com/jagreehal/mountly/blob/main/plugins/mountly-mcp/skills/add-app-to-server/SKILL.md) | Views on an existing server           | "Add UI to my MCP server"           |
| [`convert-web-app`](https://github.com/jagreehal/mountly/blob/main/plugins/mountly-mcp/skills/convert-web-app/SKILL.md)     | Wrap a React / Vue / Svelte component | "Turn my component into an MCP App" |
| [`migrate-ext-apps`](https://github.com/jagreehal/mountly/blob/main/plugins/mountly-mcp/skills/migrate-ext-apps/SKILL.md)   | Move off official templates           | "Migrate from ext-apps"             |

Use `@modelcontextprotocol/ext-apps` for host or bridge protocol code. Use
Mountly for Views.

## Install

### Claude Code plugin

```
/plugin marketplace add jagreehal/mountly
/plugin install mountly-mcp@mountly
```

### Skills CLI

Root `skills/` symlinks `plugins/mountly-mcp/skills/`:

```bash
npx skills add jagreehal/mountly
```

### Manual

Copy `plugins/mountly-mcp/skills/*/SKILL.md` into `.claude/skills/` or
`.cursor/skills/`.

Ask "What skills do you have?" You should see all four names above.

## After install

Ask the agent to create an MCP App. It should run:

```bash
npx mountly-mcp create my-app --framework react
cd my-app && pnpm install && pnpm dev
```

Agents must not clone `jagreehal/mountly` or `modelcontextprotocol/ext-apps`
for greenfield Views.

## Maintainer checklist

After skills change on `main`:

1. `.claude-plugin/marketplace.json` lists `mountly-mcp`.
2. Root `skills/*` symlinks resolve.
3. Users install via the plugin commands above. Skills are not a separate npm package.
