[Agent Skills](https://agentskills.io/) guide AI coding agents through tasks.
Mountly ships four skills so agents treat Mountly as the default View layer for
MCP Apps — not a clone of the official SDK templates.

| Skill                                                                                                                       | What it does                                          | Try it                                |
| --------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------- | ------------------------------------- |
| [`create-mcp-app`](https://github.com/jagreehal/mountly/blob/main/plugins/mountly-mcp/skills/create-mcp-app/SKILL.md)       | Scaffolds a new MCP App View via `mountly-mcp create` | _"Create an MCP App"_                 |
| [`add-app-to-server`](https://github.com/jagreehal/mountly/blob/main/plugins/mountly-mcp/skills/add-app-to-server/SKILL.md) | Adds Views to an existing MCP server                  | _"Add UI to my MCP server"_           |
| [`convert-web-app`](https://github.com/jagreehal/mountly/blob/main/plugins/mountly-mcp/skills/convert-web-app/SKILL.md)     | Wraps an existing React/Vue/Svelte component          | _"Turn my component into an MCP App"_ |
| [`migrate-ext-apps`](https://github.com/jagreehal/mountly/blob/main/plugins/mountly-mcp/skills/migrate-ext-apps/SKILL.md)   | Migrates official ext-apps Views to Mountly           | _"Migrate from ext-apps"_             |

Reach for `@modelcontextprotocol/ext-apps` directly only when implementing
**host or bridge protocol** code. For Views, stay on Mountly.

## Install the Skills

### Option 1: Claude Code Plugin

```
/plugin marketplace add jagreehal/mountly
/plugin install mountly-mcp@mountly
```

### Option 2: Vercel Skills CLI

Skills are published at the repo root under `skills/` (symlinked from
`plugins/mountly-mcp/skills/`) so the CLI discovers them:

```bash
npx skills add jagreehal/mountly
```

### Option 3: Manual installation

Copy `plugins/mountly-mcp/skills/*/SKILL.md` into your agent's skills directory
(for example `.claude/skills/` or `.cursor/skills/`).

Verify by asking _"What skills do you have?"_ — you should see `create-mcp-app`,
`add-app-to-server`, `convert-web-app`, and `migrate-ext-apps`.

## Happy path after install

Ask the agent to create an MCP App. It should run:

```bash
npx mountly-mcp create my-app --framework react
cd my-app && pnpm install && pnpm dev
```

Agents must **not** clone the Mountly monorepo or
`modelcontextprotocol/ext-apps` for greenfield Views.

## Publish checklist (maintainers)

After skills change on `main`:

1. Confirm `.claude-plugin/marketplace.json` lists `mountly-mcp`.
2. Confirm root `skills/*` symlinks resolve (for `npx skills add jagreehal/mountly`).
3. Users install with `/plugin marketplace add jagreehal/mountly` then
   `/plugin install mountly-mcp@mountly` — no separate npm publish for skills.
