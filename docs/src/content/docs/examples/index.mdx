## Embeds

The consuming page adds one script tag and installs nothing.

<LiveExample path="react-embed/host.html" title="Script-tag embed" height="380px" />

Reload with the Network panel open. `embed.js` arrives at 4.4 KB gzipped, then
the component chunk and React follow because an element is on the page. Open
**View details**, then press **Add 250 to balance** a few times: the number
changes and the panel stays open, so assigning the property patched props
instead of remounting. The card is styled with Tailwind, built by the same
config that produced the elements.

| Demo                                                                    | What it shows                                                                                                                                                            |
| ----------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| <a href={exampleUrl("react-embed/host.html")}>Script-tag embed</a>      | One React component as `<acme-payments-summary>`. `balance="1250"` arrives as a number because the props type says so, and `onViewDetails` fires a `view-details` event. |
| <a href={exampleUrl("mixed-embed/host.html")}>Mixed-framework embed</a> | React, Vue and Svelte from one build, with no compiler named in the config. Each framework chunk downloads only when one of its elements connects.                       |

Guide: [Script-tag embeds](/mountly/concepts/script-embeds/).

## Runtime

The host page runs mountly and mounts widgets on user intent.

<LiveExample path="quickstart/host.html" title="Quickstart host" height="320px" />

Hover the button before clicking it. The widget module is fetched on hover and
mounted on click, so the click costs no network time.

The MCP app preview runs **locally only**. MCP Apps §8.4 requires the host and
the sandbox proxy to sit on different origins, and this site serves everything
from one. Run `pnpm --filter mcp-app-demo verify`, which starts them on separate
ports.

## Run locally

From the repo root, after `pnpm install && pnpm -r build`:

```bash
pnpm --filter mountly-docs run stage-examples
pnpm --filter mountly-docs dev
```

Each example also has its own dev server and port, listed in
[`docs/examples/README.md`](https://github.com/jagreehal/mountly/blob/main/docs/examples/README.md).
