# Mountly MCP Apps plugin

Agent Skills for building MCP Apps Views with [`mountly-mcp`](../../packages/mcp-apps/README.md).

| Skill | Ask for |
| --- | --- |
| [`create-mcp-app`](./skills/create-mcp-app/SKILL.md) | "Create an MCP App" |
| [`add-app-to-server`](./skills/add-app-to-server/SKILL.md) | "Add UI to my MCP server" |
| [`convert-web-app`](./skills/convert-web-app/SKILL.md) | "Turn my component into an MCP App" |
| [`migrate-ext-apps`](./skills/migrate-ext-apps/SKILL.md) | "Migrate from ext-apps" |

Install: see [Agent Skills](https://mountly.dev/mcp-apps/agent-skills/) on the docs site.

```
/plugin marketplace add jagreehal/mountly
/plugin install mountly-mcp@mountly
```

Or: `npx skills add jagreehal/mountly` (discovers root `skills/`).
